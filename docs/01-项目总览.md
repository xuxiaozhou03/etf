# 01-项目总览

## 📖 文档概述

本文档是量化回测系统的总览文档，提供项目整体架构、技术栈、包结构和快速开始指南。

**系统定位：** 一个基于日K线收盘价交易的量化回测系统，从前复权数据采集到结果展示形成完整闭环。

**目标读者：** 项目负责人、架构师、新成员

## 1. 项目概述

### 1.1 核心功能

| 功能模块      | 说明                                                |
| :------------ | :-------------------------------------------------- |
| **数据采集**  | 从前复权API获取日K线数据，自动获取ETF列表并智能过滤 |
| **数据存储**  | SQLite + Prisma 持久化存储，支持增量/全量同步       |
| **阶段收益**  | 周/月/季/年/YTD收益预计算存储，支持快速查询         |
| **ETF排行榜** | 多周期排序、分类筛选、横向对比                      |
| **策略回测**  | 日K线收盘价交易，支持自定义策略                     |
| **风控能力**  | 止损、止盈、仓位控制、日亏损限制                    |
| **量化指标**  | 收益指标、风险指标、交易统计、基准对比              |
| **结果展示**  | 控制台报告、数据导出（JSON/CSV）                    |

### 1.2 系统特点

- ✅ 前复权价格处理（API直接获取，无需额外计算）
- ✅ pnpm workspace 管理多包 monorepo
- ✅ 完整的费用模拟（佣金、印花税、过户费）
- ✅ 统一的错误处理机制（Result类型）
- ✅ API请求容错与限流策略
- ✅ 增量/全量数据同步策略
- ✅ ETF列表自动获取与智能过滤

## 2. 技术架构

### 2.1 整体架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                  1. 获取ETF列表                                 │
│  ETF API → 所有ETF → 过滤规则                                   │
│  (trackingIndex≠null + 规模>3亿 + 同指数取最大)                 │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                  2. 存储到数据库                                │
│  Security表 → 保存过滤后的ETF信息 (code/name/market/category)   │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                  3. 同步K线数据                                 │
│  对每个ETF → K线API (adjust=1) → 存储到Kline表                 │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                  4. 计算阶段收益                                │
│  对每个ETF → 周/月/季/年/YTD收益 → 存储到PeriodReturn表         │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                  5. 数据服务                                    │
│  日K线 ← 从Kline表读取                                         │
│  阶段收益 ← 从PeriodReturn表读取                                │
│  ETF排行榜 ← 从PeriodReturn表查询排序                          │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                  6. 回测执行                                    │
│  策略层 → Signal → 执行层 → ExecutionResult                    │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                  7. 结果分析                                    │
│  结果层 → QuantResult (含基准对比)                             │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                  8. 结果展示                                    │
│  展示层 → 控制台报告 / 图表 / 导出文件                         │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 分层说明

| 层级           | 职责                         | 关键组件                    |
| :------------- | :--------------------------- | :-------------------------- |
| **数据采集层** | API调用、数据解析、重试限流  | DataFetcher, ETFFetcher     |
| **数据存储层** | SQLite持久化、Prisma Schema  | DataWriter, Prisma          |
| **数据服务层** | 数据读取、阶段收益、排行榜   | DataService, RankingService |
| **策略层**     | 交易决策、风控、参数配置     | Strategy, BaseStrategy      |
| **执行层**     | 模拟交易、账户管理、费用计算 | BacktestExecutor            |
| **结果层**     | 量化指标、基准对比           | ResultAnalyzer              |
| **展示层**     | 报告输出、数据导出           | ConsolePresenter            |
| **回测引擎**   | 流程编排、生命周期管理       | BacktestEngine              |

### 2.3 技术栈

| 类别         | 技术              | 说明             |
| :----------- | :---------------- | :--------------- |
| **包管理**   | pnpm + workspace  | Monorepo 管理    |
| **语言**     | TypeScript 5.0+   | 类型安全         |
| **数据库**   | SQLite + Prisma   | 轻量级持久化     |
| **测试**     | Vitest            | 单元测试         |
| **构建**     | tsup              | 多格式构建       |
| **代码规范** | ESLint + Prettier | 代码质量         |
| **API请求**  | fetch + p-retry   | 带重试的HTTP请求 |
| **错误处理** | Result<T, E> 模式 | 统一错误处理     |

## 5. 快速开始

### 5.1 安装与构建

```bash
# 1. 克隆项目
git clone <repository-url>
cd quant-backtest

# 2. 安装依赖
pnpm install

# 3. 生成Prisma客户端
pnpm --filter @quant-backtest/db prisma:generate

# 4. 初始化数据库
pnpm --filter @quant-backtest/db db:migrate

# 5. 构建所有包
pnpm build
```

### 5.2 数据同步

```bash
# 1. 同步ETF列表（仅列表）
pnpm sync:etfs

# 2. 同步ETF列表 + K线数据
pnpm sync:etfs --syncKline

# 3. 同步单只ETF
pnpm sync --code 510300.SH --name 沪深300ETF华泰柏瑞

# 4. 批量同步
pnpm sync --config ./config/etfs.json
```

### 5.3 运行回测

```bash
# 基础回测
pnpm example:basic

# ETF排行榜
pnpm example:etf

# 参数优化
pnpm example:optimize
```
