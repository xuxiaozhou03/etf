# 08-快速开发指南

## 📖 文档概述

本文档是量化回测系统的**快速开发指南**，帮助开发者快速搭建开发环境、理解开发流程、掌握调试技巧，并能够独立开发新的策略或功能模块。

**目标读者：** 所有开发者

## 1. 环境准备

### 1.1 系统要求

| 项目         | 要求                           |
| :----------- | :----------------------------- |
| **操作系统** | macOS / Linux / Windows (WSL2) |
| **Node.js**  | >= 18.0.0                      |
| **pnpm**     | >= 8.0.0                       |
| **Git**      | >= 2.30.0                      |
| **SQLite**   | 内置（无需额外安装）           |

### 1.2 安装步骤

```bash
# 1. 安装 pnpm（如果尚未安装）
npm install -g pnpm

# 2. 克隆项目
git clone <repository-url>
cd quant-backtest

# 3. 安装依赖
pnpm install

# 4. 生成Prisma客户端
pnpm --filter @quant-backtest/data prisma:generate

# 5. 初始化数据库
pnpm --filter @quant-backtest/data db:migrate

# 6. 构建所有包
pnpm build

# 7. 运行测试验证
pnpm test
```

### 1.3 环境变量配置

```bash
# .env
DATABASE_URL="file:./data.db"
LOG_LEVEL="info"
API_RETRY_COUNT="3"
API_RETRY_MIN_TIMEOUT="1000"
API_RATE_LIMIT_WAIT="5000"
```

## 3. 开发流程

### 3.1 新增策略开发流程

```
1. 创建策略文件
   → examples/strategies/my-strategy.ts

2. 实现策略类
   → 继承 BaseStrategy 或实现 Strategy 接口

3. 本地测试
   → 使用示例数据运行回测

4. 添加到CLI
   → 在 packages/cli/src/index.ts 中注册

5. 编写测试
   → tests/unit/strategies/my-strategy.test.ts

6. 提交代码
   → 创建PR，合并到主分支
```

### 3.2 开发命令

| 命令                           | 说明                    |
| :----------------------------- | :---------------------- |
| `pnpm dev`                     | 所有包开发模式（watch） |
| `pnpm build`                   | 构建所有包              |
| `pnpm test`                    | 运行所有测试            |
| `pnpm lint`                    | 代码检查                |
| `pnpm format`                  | 代码格式化              |
| `pnpm --filter <package> dev`  | 单包开发模式            |
| `pnpm --filter <package> test` | 单包测试                |

### 3.3 策略开发模板

```typescript
// examples/strategies/my-strategy.ts

import {
  DailyCandle,
  AdviceContext,
  Signal,
  FilledOrder,
} from "@quant-backtest/core";
import { BaseStrategy } from "@quant-backtest/strategy";
import { calculateSMA } from "./indicators"; // 使用第三方指标库

/**
 * 我的策略
 * 描述策略逻辑
 */
export class MyStrategy extends BaseStrategy {
  readonly name = "我的策略";

  private period: number;
  private hasPosition = false;

  constructor(
    period: number = 10,
    config?: {
      stopLossRate?: number;
      takeProfitRate?: number;
      maxPositionRate?: number;
    },
  ) {
    super(config);
    this.period = period;
  }

  /**
   * 策略初始化
   */
  init(): void {
    console.log(`${this.name} 初始化完成`);
  }

  /**
   * 核心决策方法
   */
  next(candle: DailyCandle, context: AdviceContext): Signal | null {
    // 1. 计算指标
    const prices = context.historyCandles.map((c) => c.close);
    const ma = calculateSMA(prices, this.period);
    const lastMA = ma[ma.length - 1];

    if (lastMA === undefined) return null;

    // 2. 交易逻辑
    // 示例：价格突破均线买入，跌破均线卖出
    if (candle.close > lastMA && !this.hasPosition) {
      const shares = Math.floor((context.balances.free * 0.8) / candle.close);
      if (shares > 0) {
        this.hasPosition = true;
        return {
          action: "buy",
          quantity: shares,
          price: candle.close,
          reason: `价格突破MA${this.period}`,
        };
      }
    }

    if (candle.close < lastMA && this.hasPosition) {
      const position = context.positions[context.symbol];
      if (position) {
        this.hasPosition = false;
        return {
          action: "sell",
          quantity: position.quantity,
          price: candle.close,
          reason: `价格跌破MA${this.period}`,
        };
      }
    }

    return null;
  }

  /**
   * 订单成交回调
   */
  onOrderFilled(order: FilledOrder): void {
    console.log(
      `[${order.tradeDate}] ${order.side} ${order.quantity}股 @ ${order.price}`,
    );
  }

  /**
   * 策略清理
   */
  cleanup(): void {
    console.log(`${this.name} 回测结束`);
  }
}
```

## 5. 常见问题

### 5.1 构建问题

| 问题                                        | 解决方案                                                  |
| :------------------------------------------ | :-------------------------------------------------------- |
| `Cannot find module '@quant-backtest/core'` | 运行 `pnpm build` 确保所有包已构建                        |
| `Prisma Client not found`                   | 运行 `pnpm --filter @quant-backtest/data prisma:generate` |
| `TypeScript compilation errors`             | 运行 `pnpm build` 查看完整错误信息                        |

### 5.2 数据问题

| 问题             | 解决方案                                        |
| :--------------- | :---------------------------------------------- |
| `未找到股票数据` | 先运行 `pnpm sync:etfs --sync-kline` 同步数据   |
| `数据验证失败`   | 检查日期范围是否有效，或删除 `data.db` 重新同步 |
| `API请求失败`    | 检查网络连接，或调整 `.env` 中的重试配置        |

### 5.3 回测问题

| 问题         | 解决方案                           |
| :----------- | :--------------------------------- |
| `资金不足`   | 检查策略中的仓位管理逻辑           |
| `持仓不足`   | 检查策略中的持仓跟踪状态           |
| `策略无信号` | 检查指标计算是否正确，数据是否充足 |

## 6. 开发规范

### 6.1 代码规范

```typescript
// ✅ 好的实践
export class GoodStrategy extends BaseStrategy {
  readonly name = "好策略";

  next(candle: DailyCandle, context: AdviceContext): Signal | null {
    // 使用有意义的变量名
    const currentPrice = candle.close;
    const freeCash = context.balances.free;

    // 边界检查
    if (freeCash <= 0) return null;

    // 使用 reason 记录决策依据
    return {
      action: "buy",
      quantity: Math.floor((freeCash * 0.8) / currentPrice),
      price: currentPrice,
      reason: "买入信号",
    };
  }
}

// ❌ 不好的实践
export class BadStrategy {
  n(c: any, ctx: any): any {
    // 变量名不清晰，类型不明确
    if (c.c > 10) return { a: "buy", q: 100, p: c.c };
    return null;
  }
}
```

## 7. 发布流程

### 7.1 版本号规则

```
主版本号.次版本号.补丁号

主版本号：不兼容的API修改
次版本号：向下兼容的功能新增
补丁号：向下兼容的问题修复
```

### 7.2 发布步骤

```bash
# 1. 更新版本号
pnpm version patch  # 或 minor / major

# 2. 构建所有包
pnpm build

# 3. 运行测试
pnpm test

# 4. 提交并打标签
git add .
git commit -m "chore: release v5.2.0"
git tag v5.2.0

# 5. 推送到远程
git push && git push --tags
```
