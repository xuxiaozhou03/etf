| 项目 | 内容 |
| --- | --- |
| 版本 | v0.2 |
| 日期 | 2026-08-20 |

---

## 1. 背景与目标

### 1.1 背景

- A 股 ETF 品种丰富（宽基 / 行业 / 主题 / 跨境 / 债券 / 商品 / 货币），是个人量化研究的理想载体：无个股黑天鹅、交易规则清晰、数据公开免费可得。
- 市面上通用回测平台存在数据受限、规则不透明、无法批量扫描等问题，个人研究者需要一套自建、可掌控细节的本地回测系统。

### 1.2 目标

构建一个**本地运行的 A 股 ETF 日线量化回测系统**，支持：

- 单策略单标的的精细回测与绩效分析；
- 多策略、多标的、多参数的批量回测与横向对比；
- 全市场扫描 / 选股式回测，输出标的排名与入选名单。

### 1.3 非目标（明确不做）

- 不做实盘下单、信号推送、模拟盘；
- 不做分钟级 / 盘中高频回测；
- 不做多用户、权限、云端部署；
- 不做自动化因子挖掘 / AutoML 平台（大规模特征工程流水线不属于核心目标）；
- 机器学习限定为"ML 增强选股"一种策略类型（可选阶段），不承诺通用 ML 平台能力；
- 不做个股（股票）回测，仅限 ETF。

## 2. 用户与使用场景

### 2.1 用户画像

- 个人投资者 / 量化研究者；
- 具备基础编程与金融常识，希望透明、可复现地验证 ETF 策略；
- 单机使用，数据本地存储。

### 2.2 核心场景

| 编号 | 场景 | 用户诉求 |
| --- | --- | --- |
| S1 | 单策略单标的 | 验证"双均线策略跑沪深300ETF"的表现，看净值、回撤、交易明细 |
| S2 | 多策略批量回测 | 同一批标的上对比多策略 / 多参数组合，找出稳健参数区间 |
| S3 | 全市场扫描 / 选股 | 在全部（或筛选后的）ETF 上跑动量策略，输出排名与入选名单 |
| S4 | 数据维护 | 手动或定时更新行情数据，查看数据覆盖与更新时间 |

## 3. 功能需求

### FR1 数据管理

| 编号 | 需求 | 状态 | 说明 |
| --- | --- | --- | --- |
| FR1.1 | ETF 列表与快照获取 | ✅ 已落地 | 红火箭 `findListByEtf`（`pageSize=2000` 一次全量约 1640 只）；插入前精选：规模 > 3 亿元、有跟踪指数、排除货币/债券/黑名单，每个跟踪指数取规模最大一只 |
| FR1.2 | ETF 元数据字段 | ✅ 已落地 | 已存：代码、名称、规模、溢价率、跟踪指数名称（`trackingIndex`）与代码（`trackIndex`） |
| FR1.3 | 日线行情获取 | ✅ 已落地 | 芝士财富 `dayKV2`：全量日K线 OHLCV+成交额，附带复权因子与流通份额；前复权由因子派生 |
| FR1.4 | 本地存储 | ✅ 已落地 | SQLite 单库 `data/etf.db`，5 表（`etf_list` / `daily_kline` / `adjust_factors` / `float_shares` / `crawl_state`）；支持增量更新与全量重建 |
| FR1.5 | 数据更新 | ◐ 部分 | 手动一键更新已落地；增量按 `last_run_at` 与最近 A 股交易日 15:00 收盘判定（失败直接重跑）。定时任务、覆盖区间与更新时间展示待补充 |
| FR1.6 | 数据质量检查 | ⚠ 未落地 | 停牌/缺失日显式标记、复权一致性校验、异常值（涨跌幅超限）标记（见第 9 节） |

#### 数据源接口说明（已验证）

- **ETF 列表**：`GET https://hongsehuojian.com/fundex-quote/allPage/findListByEtf`
  - 参数：`classA`（01宽基/02行业主题/03策略/04增强/05跨境/06商品/07债券/08货币）、`classB`、`orderBy`（如 `l.scale`）、`order`、`pageSize`、`pageNo`
  - 实测：`pageSize=2000&pageNo=1` 一次返回全部约 1640 只；响应含 代码/名称/规模/溢价率/跟踪指数 及行情与各区间业绩快照；本系统仅落元数据，行情与业绩由日K线派生
- **日K线**：芝士财富 `GET /api/v4/dayKV2/{code}?t={t}`
  - 鉴权：`apiOuth` 公开取 token + AES-ECB 加密块 + MD5 生成 `zstokv1` 头与 `t` 参数（已内置并实测，见 `etf_quant/datasource/kline.py`）
  - 返回：全量日K线 `[date, prev_close, open, high, low, close, volume, amount]` + `factors` 复权因子 + `floatShares` 流通份额
- 列表接口为快照型；日K线全量拉取，增量判定按最近 A 股交易日收盘时刻

### FR2 标的池与筛选

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR2.1 | 自定义标的池 | 手动添加/删除 ETF 代码；支持按类型、上市时间、近N日成交额阈值筛选 |
| FR2.2 | 全市场池 | 默认包含数据源提供的全部场内 ETF |
| FR2.3 | 池复用 | 标的池可命名保存，供批量回测与全市场扫描复用 |

### FR3 策略管理

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR3.1 | 内置策略模板 | 双均线交叉、动量轮动（相对强弱）、网格交易、定期再平衡/定投、布林带、RSI 择时 |
| FR3.2 | 自定义策略 | 指标库（MA/EMA/RSI/MACD/BOLL/ATR/动量等）+ 条件规则（金叉/死叉/突破/阈值，支持 AND/OR 组合） |
| FR3.3 | 参数化 | 策略参数可配置；支持单参数与多参数网格扫描 |
| FR3.4 | 策略保存 | 策略配置可命名保存、编辑、复用 |
| FR3.5 | 因子库 | 内置常用因子（动量、波动率、流动性、趋势、量价等），基于日线 OHLCV/成交额计算；因子命名保存、复用 |
| FR3.6 | 因子策略 | 支持单因子打分排序 / 多因子加权评分，作为选股式策略的一种（输出标的排名与权重） |
| FR3.7 | 因子有效性分析 | 计算因子 IC / ICIR、分层（分组）回测，展示因子与未来收益的关系 |
| FR3.8 | ML 增强选股（可选阶段） | 以因子为特征，用轻量 ML 模型（如 sklearn 线性/树模型）输出选股名单；必须 walk-forward 训练回测，防止前视偏差与过拟合 |

### FR4 回测引擎（A 股规则）

#### FR4.1 撮合与交易规则

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR4.1.1 | 交易周期 | 日线级别，信号按日生成 |
| FR4.1.2 | T+1 / T+0 规则 | 按 ETF 类型区分：股票型 ETF 默认 T+1，跨境/债券/货币/黄金 ETF 默认 T+0；可全局配置 |
| FR4.1.3 | 成交价 | 默认信号日次日开盘价成交（避免前视偏差）；可选当日收盘价成交（简化模式） |
| FR4.1.4 | 停牌处理 | 停牌日无法成交，持仓顺延至下一可交易日 |
| FR4.1.5 | 涨跌停约束 | 涨停无法买入、跌停无法卖出（按 ETF 类型涨跌幅限制：10% / 20% / 无限制） |

#### FR4.2 交易成本

| 编号 | 需求 | 默认值 | 说明 |
| --- | --- | --- | --- |
| FR4.2.1 | 佣金 | 万2.5 双边 | 可配置；支持最低佣金（默认 0 元，可设 5 元） |
| FR4.2.2 | 印花税 | 0 | ETF 免印花税，系统固定为 0 |
| FR4.2.3 | 滑点 | 0.1% 单边 | 可配置 bps；可按成交额比例建模 |

#### FR4.3 仓位与执行

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR4.3.1 | 仓位模式 | 全仓 / 固定比例 / 目标权重再平衡 |
| FR4.3.2 | 资金模型 | 初始资金可配置；收益再投资 |
| FR4.3.3 | 基准 | 默认沪深300（510300 或指数），可配置；用于超额收益计算 |

### FR5 三种回测模式

| 编号 | 模式 | 输入 | 输出 |
| --- | --- | --- | --- |
| FR5.1 | 单策略单标的 | 1 策略 × 1 标的 × 1 组参数 | 净值曲线、回撤曲线、交易明细、完整绩效指标、持仓变化 |
| FR5.2 | 多策略批量回测 | 策略 × 标的 × 参数网格 | 结果对比表（按绩效指标排序）、参数敏感度热力图、最优组合 |
| FR5.3 | 全市场扫描 / 选股 | 策略 + 筛选后的标的池 | 标的评分排名表、入选名单（如动量前N）、历史入选稳定性统计 |

### FR6 绩效评估指标

#### FR6.1 必含指标

- 总收益率、年化收益率、年化波动率；
- 最大回撤及回撤区间、夏普比率、索提诺比率、卡玛比率；
- 胜率、盈亏比、交易次数、平均持仓周期；
- 换手率（年化）、Alpha、Beta、信息比率、相对基准超额收益。

#### FR6.2 可扩展指标

- 滚动收益率、月度收益分布、逐笔交易收益分布；
- 参数稳健性（相邻参数结果波动度）。

### FR7 可视化

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR7.1 | 净值曲线 | 策略 vs 基准，含回撤水位 |
| FR7.2 | 回撤曲线 | 最大回撤区间标注 |
| FR7.3 | 持仓/仓位图 | 仓位比例随时间变化 |
| FR7.4 | 交易点位图 | 买卖点标注在 K 线/净值图上 |
| FR7.5 | 批量对比 | 对比表 + 参数热力图（ECharts 或等效图表库） |

### FR8 报告导出

- 单策略回测报告导出为 HTML（自包含，含图表与配置）；
- 交易明细、净值序列导出 CSV；
- 批量对比 / 全市场扫描结果导出 CSV / Markdown 表格。

### FR9 系统管理

- 全局默认配置：佣金、滑点、基准、初始资金；
- 数据任务状态页：更新进度、失败重试、日志查看；
- 数据目录与缓存管理（清理、重建）。

## 4. 非功能需求

### NFR1 性能

| 场景 | 目标 |
| --- | --- |
| 单标的 10 年日线（约 2400 根 K 线）回测 | < 1 秒（不含数据加载） |
| 批量回测（100 组参数 × 10 标的） | < 1 分钟 |
| 全市场扫描（约 1000 只 ETF × 单策略） | < 3 分钟（向量化） |

### NFR2 技术选型（建议，待确认）

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 语言 | Python 3.9+（当前实测 3.9） | 量化生态成熟（pandas/numpy） |
| 回测引擎 | 自研向量化引擎（pandas/numpy） | 透明可控，天然适配三种回测模式 |
| 后端 | FastAPI + Uvicorn | 轻量、异步、易写 API |
| 前端 | React + Vite + ECharts（或 Vue3） | 图表能力强，本地单机足够 |
| 存储 | SQLite 单库（元数据/日线/状态全量，无 Parquet） | 数据量小（精选约 1000 只 × 10 年 ≈ 240 万行），本地足够 |
| 数据源 | hongsehuojian.com（ETF 列表/快照）+ stock.cheesefortune.com（日K线/复权因子/流通份额） | 列表一次全量、字段丰富；芝士财富日线含因子与份额；数据源接口抽象化便于切换 |
| 调度 | APScheduler 或系统 cron（可选） | 定时更新行情 |

### NFR3 正确性与可信度

- 严格控制前视偏差：信号使用 T 日收盘数据，成交默认 T+1 开盘价；
- 复权逻辑统一（回测统一使用前复权数据，并在配置中声明）；
- 数据源可追溯：每份数据记录来源与抓取时间；
- 回测结果可复现：记录完整参数、数据版本、成本设置。

### NFR4 其他

- 本地运行，无外部数据上传，数据不出本机；
- 单用户，无需登录权限体系；
- 代码结构分层（数据层 / 策略层 / 引擎层 / API 层 / 前端），便于扩展。

## 6. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 第三方接口变动 / 频率限制 | 数据获取失败 | 数据源接口抽象化，预留本地文件等其他备源；抓取限速与重试 |
| 前复权数据跨更新跳变 | 回测结果不可复现 | 记录数据版本与抓取日期；必要时改用"不复权 + 复权因子"方案 |
| 参数扫描过拟合 | 回测漂亮、实盘失效 | 提供滚动样本外验证提示；参数稳健性热力图 |
| ML 特征前视偏差 / 过拟合 | 模型在样本外失效 | walk-forward 强制滚动训练；特征只用 T 日及以前数据；限制特征数量与模型复杂度 |
| 小规模 ETF 流动性差 | 滑点低估，结果失真 | 扫描时按成交额/规模过滤；滑点可调高 |
| ETF 历史短 / 已清盘 | 数据缺失或幸存者偏差 | 过滤上市不足 N 日的标的；报告中标注数据区间 |
| 日线模型简化（收盘价近似） | 与实盘有偏差 | 报告声明模型假设（成交价、滑点、停牌处理方式） |

## 7. 验收标准（总）

1. 能获取并更新全市场 ETF 日线数据，数据覆盖与更新时间可查询；
2. 单策略单标的回测：净值曲线与手算示例可核对（提供一条手工验证用例）；
3. 批量回测：支持至少 6 个内置模板策略、自定义规则策略、参数网格，输出对比表与热力图；
4. 全市场扫描：对筛选池输出排名与入选名单，含入选稳定性统计；
5. 交易成本（佣金/滑点）与 T+1、涨跌停、停牌规则生效且可配置；
6. 报告可导出为自包含 HTML 与 CSV；
7. 因子库可计算 IC/ICIR 与分层回测，因子策略可输出排名名单；
8. 性能满足 NFR1 目标。
